# Albino Crocodile - $CROCODILE

A landing page for the Solana meme coin $CROCODILE, inspired by Werner Herzog's documentary on albino crocodiles.

## Description

This project is a static HTML website designed as a promotional landing page for the $CROCODILE meme coin on Solana. It features a cinematic design with quotes from Werner Herzog, background videos, and interactive elements like a copyable contract address.

## Features

- Animated background with grain and dust effects
- Werner Herzog quotes and Vimeo video embed
- Copyable contract address box (currently TBA)
- Social media links (X/Twitter)
- Responsive design
- Glassmorphism UI elements

## Setup

1. Clone or download the repository.
2. Open `index.html` in a web browser.

No server required; it's a static site.

## Usage

- View the landing page to learn about $CROCODILE.
- Click the contract address box to copy the CA (when available).
- Follow on social media for updates.
